# Task 3: Paper Implementation - Back-propagation (1986)

This repository contains an independent PyTorch implementation of the **Symmetry Detection Task** proposed in the landmark 1986 paper: *"Learning representations by back-propagating errors"* by Rumelhart, Hinton, and Williams.

## Requirements
* Python 3.8+
* PyTorch (`pip install torch`)

## How to Run
Navigate to the root directory of this repository and run the training script:

```bash
python src/symmetry_detection.py
